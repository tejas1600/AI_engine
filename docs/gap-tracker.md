# Gap tracker: what this project covers

Source: TejasPatil_TechGapTracker_v2 (rebuilt 23 October 2026). Every row starts as Not started, even tools you used before, because this project treats all skills as fresh.

Rule: a gap moves to Closed only when a built, working project backs it and it is on the CV in what-I-built style.
